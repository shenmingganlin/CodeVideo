# 素材清单

平时收集的素材放在这个目录，做作品时先查这里。代码里用 `staticFile("library/<分类>/<文件名>")` 引用。

- `sfx/`：音效
- `bgm/`：背景音乐
- `svg/`：图标、角色、装饰图形
- `images/`：图片、贴图

每加一个素材，在对应分类下补一行：文件名、内容描述（听起来/看起来是什么样、时长）、来源、许可。描述写得越具体，越容易挑对；来源和许可决定能不能发 B 站。
