# 模板：原地压扁

- 效果：一张透明图原地压扁、横向撑宽，再弹回来、纵向略拉长，循环往复（"duang duang"）。
  适合用来搞笑强调、配一句吐槽。上面可以再叠文字或音效
- 用户提供：一张透明 PNG/WEBP（自己的图、生图，或素材库里的），要自带不透明深色描边
- 要问的：
  - 压扁幅度：轻 0.45（推荐，模板默认，适合细节多的图）/ 中 0.36 / 狠 0.30。小图上狠档会压成一条
  - 节奏：一下 0.48 秒 = 12 帧（推荐，每秒两下，参考视频的节奏）/ 更慢 0.6 秒 = 15 帧 / 更急 0.4 秒 = 10 帧，
    都按 25fps 算
  - 图四周有没有透明留白：不确定就跑 `npm run image-box` 量，量出来右边距或下边距大就填 box
- 固定做法（不再问）：240×240 透明 GIF、25fps（微信上限，见坑）、底边固定原地压、
  一个循环正好压一次。压和缩都用 inOut 正弦、合成一条平滑的往复曲线，顶部和底部都不做硬停
  （底部最多留 1 帧），停久了会像卡住，起步太快会像瞬移
- 步骤：
  1. 拿到图，放进 `public/stickers/<套系>/`；生图要带"大轮廓、粗深色描边、少细节、透明背景"，
     `--background=transparent`，再用 `npm run sticker-art` 处理（自带描边的图可以 `--outline=0`）。
     要处理的原图别放在 `--out` 目录里：输出和原图同名，会盖掉原图，脚本会直接报错
  2. 图有留白就 `npm run image-box -- <图>`，把打印出来的 `box={…}` 粘进参数；没有留白就不用
  3. 写 Composition：`<StickerComposition>` 包 `<Squish src=… />`，`fps={25}`，`durationInFrames` 按节奏填
     12 / 15 / 10，参数见 `Squish.tsx`。素材不是图片（比如代码画的 SVG）时不用 `<Squish>`，
     直接调导出的 `squishScaleAt(frame, durationInFrames, depth, peak, hold)` 拿纵向缩放，
     横向照 `1 + (1 - scaleY) * stretch` 算，以底边中点为轴缩放，手感和图片版一致
  4. `npm run sticker -- <id>` 导出校验，看预览图确认最扁时不顶画布边、浅色深色底都干净
- 参数：`depth` 压到多扁（0.45），`stretch` 横向系数（0.55），`peak` 弹起拉到多少（1.10），
  `size` 静止可见宽（176），`ground` 底边高度（228），`hold` 压住几帧（1；0 是最扁那一下不停、碰到就弹），
  `box` 留白范围。弹到最高的那帧在循环正中（`durationInFrames / 2` 取整，至少 `hold + 2`）
- 坑：
  - 帧率绝对不要超过 25fps：50fps 的 GIF 文件合法，但微信播放时会把 2/100 秒的帧往上取整，整个慢一倍
  - `size` 的上限是 232 / (1 + (1 - depth) × stretch)，超了最扁时会顶出画布。量出留白后 size 指「内容宽」，
    图才能贴住地面
  - 图必须自带不透明描边：GIF 的透明只有 1 位，抗锯齿的半透明边会变成一圈脏点；没有描边就用 sticker-art 加
  - box 是右开区间（right、bottom 是内容的下一列 / 下一行），直接和 left、top 相减就是宽高
- 来源：橘猫 `CatSquish`、DeepSeek 鲸鱼两个表情（作品只在私有仓库）
