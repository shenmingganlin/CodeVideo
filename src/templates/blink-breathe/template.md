# 模板：眨眼呼吸

- 效果：角色站着轻微呼吸（以脚底为基点纵向伸缩），循环里眨一次眼。适合做"待机""发呆""盯着你"一类表情的底子，上面可以再叠文字或道具
- 用户提供：角色（自己的图、一段描述让生图画，或现成的透明 PNG），以及闭眼差分（没有就用图生图做）
- 要问的：
  - 角色从哪来：用户给图（推荐，最像用户要的）/ 生图 / 代码画
  - 要不要配文字、写什么
  - 时长：20fps × 40 帧 = 2 秒（推荐，呼吸节奏自然）/ 60 帧更慢
- 固定做法（不再问）：240×240 透明 GIF、深色外描边、脚底对齐画面底部、一个循环正好呼吸一次
- 步骤：
  1. 得到睁眼图：用户的图直接用；生图要带"大轮廓、粗深色描边、少细节、透明背景"，`--background=transparent`
  2. 闭眼差分：把睁眼图当 `--image` 做图生图，提示词"保持角色、画风、描边、配色和姿势完全不变，只把眼睛改成闭眼"，不用 `--mask`
  3. `npm run sticker-art -- 睁眼.png 闭眼.png --out=public/stickers/<套系>/`，两张一起处理才对齐
  4. 表情里用 `<BlinkBreathe open=… closed=… />`，参数见 `BlinkBreathe.tsx`
  5. `npm run sticker -- <id>` 导出校验
- 参数：`blink` 闭眼帧区间（默认 70% 处 4 帧），`breathe` 幅度（默认 0.025），`bottom` 脚底留白
- 坑：差分图要和睁眼图一起过 sticker-art，分开处理会错位跳动；幅度超过 0.05 会像果冻
- 来源：`src/checks/StickerArtCheck.tsx`
